# Nobif4k-OCR (Mobile Web App)

A high-performance mobile document scanner & form-first autofill bridge frontend built with React, Vite, and Tailwind CSS.

## 🚀 Features
- **Step 1: Form & Mode Inspector**: Analyze target web forms to determine autofill strategies (`TOHODO`, `QUICKFORM`, `LIGHTNING`, `DIRECT`).
- **Step 2: Mobile Camera Capture**: In-memory camera capture with real-time canvas compression.
- **Step 3: OCR & Interactive Review Editor**: Review extracted key-value fields and edit values before syncing.
- **Step 4: 4-Digit Desktop Sync**: Displays a clean 4-digit code (e.g. `4829`) to autofill desktop forms via the Nobif4k Chrome Extension.

## 🛠️ Tech Stack
- React 18 + Vite
- Tailwind CSS
- Production Backend: `https://graphicat.site/api/nobif4k`
